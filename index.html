What is traditional Machine Learning?

Suppose we want to predict someone's salary from their years of experience. We have some data:

Experience xSalary y
130
240
350
460
570

A simple ML model can learn the formula:

Linear Model 
y = mx + b

// It discovers:
m = 10
b = 20

// So:
Salary = 10 × Experience + 20

// For 6 years:
y = 10(6) + 20 = 80

This is linear regression — the simplest form of machine learning.

The core idea is simple:
INPUT → mathematical formula → OUTPUT

So where does a Neural Network come in?

A single neuron starts with almost exactly the same idea.

Input x
z = mx + b
Activation Function
Output y

Mathematically:

Single Neuron 
z = mx + b

y = activation(z)
The foundation is still y = mx + b.
That's an extremely important thing to understand.

Why isn't a Neural Network just Linear Regression?

Because of the activation function.

Consider z = 2x − 2. Without activation, this produces a straight line. Now let's apply ReLU:

ReLU Definition 
ReLU(x) = x       if x > 0
           0       if x ≤ 0
x2x − 2ReLU(2x − 2)
-2-60
-1-40
0-20

The negative part has been flattened to zero. The shape is no longer a straight line — that's the beginning of non-linearity.

05

Many Neurons, Many Layers

One neuron is relatively simple. The magic happens when we connect many neurons together into layers.

Each neuron has its own m (weight) and b (bias):

Multiple Neurons 
Neuron 1 → m₁x + b₁
Neuron 2 → m₂x + b₂
Neuron 3 → m₃x + b₃

// Then activation is applied to each.
// Then another layer does it again.

Each connection carries a weight. Each node applies: z = w₁x₁ + w₂x₂ + ... + b then activation(z)

Each ● is a neuron. Each neuron does:

General Neuron 
z = w₁x₁ + w₂x₂ + w₃x₃ + b
output = activation(z)

It is still fundamentally multiplication + addition.

09

The role of the Activation Function

If we remove activation functions, something surprising happens. Even with many layers, the entire network reduces to a single linear equation:

Without Activation 
// Even with many layers:
Linear → Linear → Linear → Linear

// Reduces to:
y = mx + b

// Just another straight line!

Activation functions introduce non-linearity — that's what lets the network model curves, complex boundaries, and complicated patterns instead of only straight lines.

10

Important Activation Functions

ReLU

max(0, x)
Most common. Outputs x if positive, 0 otherwise. Used heavily inside networks.

Sigmoid

1 / (1 + e⁻ˣ)
Squashes values between 0 and 1. Great for binary probability outputs.

Softmax

eˣⁱ / Σeˣʲ
Multi-class classification. Outputs probabilities that sum to 1.0.

The most important types of Neural Networks

⬡

MLP / Feedforward

The simplest neural network. Information flows forward through basic layers.

Classification, regression, tabular data
◐

CNN

Convolutional Neural Network. Designed especially for images — learns edges → shapes → objects.

Image classification, face recognition, object detection
⟳

RNN

Recurrent Neural Network. Processes sequences and maintains information from previous steps.

Text, time series, speech, sequential data
⧖

LSTM / GRU

Improved recurrent networks designed to handle longer-term dependencies.

Time series, speech, long text sequences
✦

Transformer

The foundation for modern LLMs. Uses attention to relate different parts of a sequence.

ChatGPT, Gemini, Claude, translation, vision
⟨⟩

Autoencoder

Compresses input to a small representation, then reconstructs it.

Dimensionality reduction, anomaly detection
⚔

GAN

Generative Adversarial Network. One network generates, another detects fakes. They compete.

Image generation, style transfer
12

The Transformer & Attention

One of the most important architectures today. The key idea is attention — instead of reading sequentially, the network can focus on relevant parts of the input.
